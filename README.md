# 梦幻里程

> 单机离线的游戏收益记账工具：记录每一场搬砖的收获与损耗，算出净收益和效率。

梦幻里程是一个 Electron 桌面应用，**不联网、不登录、没有账号**。所有数据存在你自己的电脑上，
关掉应用再打开数据还在；装到新电脑上，把 `data.db` 拷过去就能继续用。

## 它解决的问题

玩一段时间下来，「今天赚了多少」往往只能靠感觉。这个工具把一局一局的收益记下来：

- 开始一局 → 点物品图标记账 → 结束并保存，成本（点卡）按分钟数自动算进去；
- 收益曲线、号组对比、活动收益排行、物品获得排行都从这些记录里来；
- 忘了点结束？下次打开会提示按实际结束时间补记，不会把点卡成本算到天亮。

## 功能

| 模块 | 说明 |
| --- | --- |
| 记录 | 计时会话、物品点选记账、损耗录入、总银两、点卡成本、暂停、多号组并行 |
| 记录列表 | 按日期 / 关键词筛选，查看明细，导出 CSV（含明细行，Excel 可直接打开） |
| 仪表盘 | 今日活动、今日概览、收益曲线、快捷入口 |
| 分析 | 收益趋势、活动收益排行、物品获得排行 |
| 号组 | 号组与角色档案、组间效率对比 |
| 活动 | 每周时间表、开始规则维护（每天 / 每周几 / 每月第几个周几）、开始前与开始时提醒 |
| 物品信息 | 物品维护、图标上传、按服务器维护三档价格 |
| 设置 | 本地档案、服务器与点卡价、默认号组、托盘与开机自启、一键初始化（清空本地数据） |
| 关于 | 版本信息、每日自动备份、导出 / 从备份恢复、手动检查更新 |

### 价格体系

物品价格按 **物品 × 服务器** 维护三档：

1. **商人收购价** — 游戏里商人玩家的收购价（可不填）
2. **个人收购价** — 游戏里玩家喊话的收购价（可不填）
3. **用户录入价** — 你认可的成交价，**必填**；记账时用的就是这一档

只有「固定价格物品」需要维护价格；浮动价格的物品在每次点选时直接录本次成交单价，
不写进价格表（写死没有意义）。记账时点到还没维护过价格的固定价物品，会当场弹出
三档价表单，填完直接入账，不必先去物品页。

点卡价（两/点）按服务器维护，开局时快照进这一场记录：之后改价只影响新记录，
已结算的历史记录仍按当时的价格计算。

### 活动提醒

活动规则支持三种：

- **每天** —— 每天的某个时间段；
- **每周** —— 每周固定的星期几；
- **每月第 N 个** —— 每月第 1～5 个指定的星期几（第 5 个 = 当月最后一个）。

内置了一批常见活动的初始规则，**只作为初始值，请以游戏内公告为准**，可在「活动」页自行修改。
提醒默认提前 10 分钟，并可选在开始时再提醒一次；点击通知会打开记录页并预选该活动，
但不会自动开始计时。

### 界面主题

顶栏右侧的调色盘按钮里可以切换两套界面，选择会记在本机，下次打开还是这一套：

| 主题 | 风格 | 可选显示模式 | 主题色 |
| --- | --- | --- | --- |
| 主题一（默认） | 新拟物：元素与背景同色，层级只靠一对明暗阴影 | 亮色 / 暗色 | 紫罗兰、靛蓝、青碧、洋红 |
| 主题二 | 柔和界面风：雾灰画布 + 纯白卡片、彩色柔光阴影、悬停浮起 | 仅亮色 | 固定靛蓝 |
| 主题三 | 玻璃拟态：深墨夜景底上的半透明面板，背景柔光斑透过 40px 模糊显出厚度 | 仅暗色 | 固定香槟金 |
| 主题四 | 俏皮野兽派：4px 黑边、零圆角、零模糊硬阴影，糖果色块与 300ms 回弹 | 仅亮色 | 固定珊瑚红 |

主题二、主题三、主题四各自按设计规范只给了一套取值（两亮一暗），切换过去时显示模式会
自动跟着走，显示模式开关与主题色选择会锁定；切回主题一即可恢复亮暗与四种主题色。

## 技术栈

- **桌面**：Electron 37（主进程持有数据库，渲染进程只经 preload 白名单调用）
- **界面**：Vue 3 + Pinia + Element Plus + Vite
- **数据**：SQLite（`@libsql/client` + drizzle-orm），进程内访问，不监听任何端口
- **路由**：Hono，以函数调用的方式挂在主进程里（`app.request()`），不启动 HTTP 服务

## 目录结构

```
apps/
  client/        渲染层（Vue 3）
  desktop/       主进程（Electron）、托盘、提醒、备份、更新检查
packages/
  core/          数据库结构、迁移、业务路由（服务器/号组/会话/统计/物品）
  shared/        共享类型与校验
scripts/         提交前的数据文件检查
```

## 开发

要求 Node ≥ 22、pnpm 11。

```bash
pnpm install
pnpm dev          # 同时启动 Vite 与 Electron
```

单跑某一层：

```bash
pnpm --filter @lc/client run dev        # 只起 Vite（http://localhost:5174）
pnpm --filter @lc/desktop run dev       # 编主进程并拉起 Electron
pnpm -r typecheck                       # 全量类型检查
pnpm lint
```

## 构建与打包

```bash
pnpm build        # 渲染层 + 主进程
pnpm pack:win     # Windows x64 安装包（NSIS），产物在 apps/desktop/release/
```

安装包为「可选安装目录 + 桌面快捷方式」的非一键安装，卸载时不会删除
`%APPDATA%\梦幻里程` 下的数据，需要彻底清除请手动删除该目录。

默认安装目录为 `%LOCALAPPDATA%\Programs\menghuanlicheng`（electron-builder 的安装目录名
只接受 ASCII，所以是拼音而不是中文名；界面标题、快捷方式、进程名仍然是「梦幻里程」）。

首次打包时 electron-builder 需要下载 NSIS 等构建工具，国内网络直连 GitHub 会超时，
可以先设镜像：

```bash
# Git Bash
export ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/
pnpm pack:win
```

## 数据放在哪

| 内容 | 路径 |
| --- | --- |
| 数据库 | `%APPDATA%\梦幻里程\data.db` |
| 上传的头像 / 物品图 | `%APPDATA%\梦幻里程\images\` |
| 自动备份 | `%APPDATA%\梦幻里程\backups\`（每天首次启动留一份，滚动保留 7 份） |

「关于」页可以看到实际路径，也能导出备份或从备份恢复（恢复前会把当前库另存为
`data-before-restore.db`，然后自动重启）。

「设置 → 一键初始化」会把本机的服务器、号组、角色、里程记录和物品价格全部清空，
昵称与头像复位，等于恢复出厂设置；确认框要等 10 秒并手动输入「我确认」才能点确定。
内置的物品目录与活动规则不受影响。**这一步不可撤销，先导出备份。**

### 图标与升级

内置物品图标随安装包一起发布，存放在渲染层资源目录。你自己上传或替换的物品图存在
用户目录，**优先级高于内置图**，升级不会被覆盖。

## 离线与隐私

- 应用运行时不做任何网络请求，界面内容（CSP）也禁止外部连接；
- 唯一的联网行为是「关于 → 检查更新」：仓库地址写死在程序里
  （`hyhy1101/menghuanlicheng`，见 `packages/shared/src/constants.ts`），
  只有手动点击时才会读取一次 GitHub Release，界面上没有可配置的入口；
  不点就完全不联网；
- 数据不出本机，没有账号、没有云同步、没有埋点。
